# Video Reference Analysis

Accept one public video link or local media file. Prefer the shared Content Analysis reference intake/context tools so measurements and follow-ups retain the same source identity. With the optional video dependencies installed, `python -m content_analysis.video_reference` also processes a public post or local file; inspect its --help before running unfamiliar options.

The analyzer prints a chat-ready report and retains temporary keyframes, a contact sheet and machine-readable measurements. Do not create a document, dashboard or report viewer. Inspect actual frames in the conversation and state precisely which timestamps/ranges were inspected. Use actual listening only when supported and record its coverage. Audio measurements and ASR are not listening.

Explain structure (hook, explanation, reveal, payoff, ending), shot size/angle/composition, overlays/captions, cut timing and transitions, zoom scale/focal point, speech/music/silence/SFX and synchronization. Separate measured, estimated, inferred, recommended and unknown. Derive tempo from audio, never cut cadence. An apparent camera move may be an edit; leave ambiguous mechanisms unresolved.

For recreation questions, connect each technique to source evidence, concrete inputs and an available tool. Verify the current capability rather than guessing a font, asset, lens or editing vendor. State approximation limits and offer the smallest useful production steps. Finished media or production changes require their own request. Reuse compatible production skills only when relevant and available; do not assume any brand defaults.
