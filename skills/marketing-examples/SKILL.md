# Marketing Examples

Identify whether the user wants inspiration, a teardown, comparison or adaptation. Use supplied examples or retrieve relevant public sources with available tools. Record source URL, date, audience, channel, format, actual text/media and access limitations. Reuse the shared Content Analysis evidence store when available; do not build another library or application.

Explain the example's job: attention, clarity, trust, differentiation, objection handling or activation. Identify the actual mechanism and evidence, then distinguish inferred intent from measured performance. Use comparable performance data only when established; missing metrics are unknown. Do not infer conversions or causation from appearance.

Extract reusable principles without copying distinctive creative expression. Apply them to a target brand or product only when the user supplies that context. Give concrete changes and the main trade-off. Deliver findings and drafts in conversation, with sources; no automatic documents, private brand rules, publishing or implementation.
